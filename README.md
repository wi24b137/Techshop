# TechShop

## Description
TechShop is a web shop project where users can browse products, add them to a shopping cart and manage their orders.

## Features
- Product overview
- Product details
- Shopping cart
- Add / remove products
- User login (optional)
- Backend with database

## Technologies
- HTML
- CSS
- JavaScript
- (Backend: e.g. Node.js / PHP)
- (Database: e.g. MySQL)

## Project Structure
/frontend → Website (HTML, CSS, JS)  
/backend → Server and database  
/docs → Planning (Backlog, Sprint Plan)
